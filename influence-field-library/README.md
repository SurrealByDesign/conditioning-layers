# Influence Field library

This directory contains the manifest-bound fields used by the legacy sidebar,
plus native [QR/UPC presets](preset-fields/v1/README.md). Keep the directory layout
and asset bytes intact. The [v1 library](v1/README.md) includes field/complement
relationships; a complement's presence does not make it a sidebar preset.

For user workflows start with the [examples](../examples/conditioning-layers/README.md).
