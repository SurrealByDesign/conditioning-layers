# v0.1.0-alpha.4 — release notes

This experimental alpha adds effective-contribution inspection and explicit selective blending to native Conditioning Layers workflows.

- **Contribution view:** inspect prepared weights for a selected layer, including FIXED conflicts, group diagnostics and pending/stale/unavailable states. It uses current edits without committing them and does not predict generated pixels.
- **Compose Blend Groups:** assign literal group names and share influence using the strongest member of each group. FIXED ownership remains global. Legacy Compose keeps its mathematics and rejects explicit assignments.
- **Examples:** a self-contained grouped Contribution tutorial with four Painted Fields, plus a separate experimental MOSS FIXED UI/API example.
- **Maintenance:** portable focused tests and corrected Balance layout expectations. The existing compact Painted Field toolbar and public loader isolation are preserved.

Krea 2 remains the supported early backend. Accepted grouped generation evidence is bounded to Krea 2 Turbo BF16 on ComfyUI 0.34.6 / frontend 1.49.6. MOSS is an example-only observation on 0.42.0 / 1.55.18, using the documented model files, 1024×1024, full coverage and aligned 2×2 FIXED field blocks. MOSS BLENDED, grouped and painted-field behavior is unqualified. Sidebar support and historical identities are unchanged.

No new runtime dependency or frontend build step. Install the complete package, restart ComfyUI and refresh the browser. Back up workflows before moving between alpha versions. Keep fields directly connected when using Contribution; unsupported topology reports unavailable.

Release preparation reuses accepted generation evidence and performs no new GPU generations. See the [developer guide](https://github.com/SurrealByDesign/conditioning-layers/blob/v0.1.0-alpha.4/docs/developer.md#alpha4-validation) for candidate checks and their limits.
